# Segurança

## Como relatar uma vulnerabilidade

Se você encontrou uma falha de segurança, **não abra uma issue pública**. Use o relato privado de vulnerabilidades do GitHub: na aba **Security** deste repositório, clique em **Report a vulnerability**. Só quem mantém o projeto vê o relato.

Conte, se puder:

- o que é a falha e onde está (arquivo, rota, tela);
- como reproduzir, passo a passo;
- o impacto que você imagina (ler dados de outra pessoa, executar código, etc.).

## O que esperar

- Confirmamos o recebimento em até 5 dias úteis.
- Mantemos você informado enquanto corrigimos.
- Depois da correção publicada, damos o crédito a você, se quiser.

## Escopo

Vale para o código deste repositório. Instâncias de terceiros são responsabilidade de quem as opera. Não faça testes que derrubem o serviço, apaguem dados ou acessem contas que não são suas.
