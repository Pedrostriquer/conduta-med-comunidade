# Logos

- `conduta-simbolo.svg` — O símbolo: quadrado `accent` (#1468d5) com a bifurcação em branco. Ícone de app, favicon, avatar.
- `conduta-simbolo-uma-cor.svg` — Versão de uma tinta só, em `ink` claro (#151a21), com o desenho vazado. Para impressão em uma cor e carimbos; num fundo escuro, inverta a cor.
- `conduta-assinatura.svg` — Símbolo e a palavra “conduta” em contorno (Hanken Grotesk 700), palavra em `ink` claro (#151a21). Para fundos claros.
- `conduta-assinatura-escuro.svg` — A mesma assinatura com a palavra em `ink` escuro (#ebedf0). Para fundos escuros.

Na interface, use o componente `Logo`, que acompanha o tema sozinho. Respiro mínimo em volta: metade da altura do símbolo.
