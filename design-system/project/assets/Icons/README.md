# Ícones

Cópias em SVG dos ícones do componente `Icon`: grade de 24px, traço de 1,75, pontas e junções arredondadas. Cada arquivo tem uma tinta só, `ink` claro (#151a21), porque um SVG em `<img>` não herda a cor do texto. Na interface, use o componente `Icon` (que usa `currentColor`); estes arquivos servem para ferramentas de design, documentos e e-mails.

`play` e `more` são preenchidos; os demais são de traço.
